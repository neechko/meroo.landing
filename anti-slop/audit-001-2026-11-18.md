# Audit 001 - meroo__ HUD landing

- **Date:** 2026-11-18
- **Mode:** AFTER (audit only; nothing is changed until findings are approved)
- **Scope:** `src/**`, `api/**`, `index.html`, `README.md`, project root
- **Rule set:** antislop core (R-01..R-40) + `antislop-ui`, `antislop-human`, `antislop-copywriting`, `antislop-layoutmobile`
- **Priority mapping:** Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW

## How this was measured

Headless Chrome 157 (CDP), dev server `http://127.0.0.1:5173`, tutorial dismissed via
`meroo.tutorial.v2=1`, intro clicked through to the HUD, then:

- layout at 360x740, 390x844, 768x1024, 1024x768, 1279x720, 1280x720, 1440x900, 1920x1080
- short windows at 1366x600, 1280x600, 1024x600, 768x600, 360x640, 720x450
- contrast computed from `getComputedStyle` colors converted from `oklch`/`oklab` to sRGB,
  composited over the stacked background (page base `#05030c`), at 1366x768
- keyboard walk with real `Input.dispatchKeyEvent` Tab/Escape, 14 tabs inside an open dialog
- focus retention measured over 35 seconds with the message textarea focused

Not measurable here: audio character, WebGL render quality, and Lanyard/Genshin live payloads.
Those still need a real browser check by the owner.

## HIGH - Hard Gate (must fix)

### 1. Em dash in visible UI copy - R-02

Nine locations:

| File | Line | Text |
|---|---|---|
| `index.html` | 16 | meta description: `meroo__ - a single-screen hub ...` |
| `src/lib/bgm.ts` | 740 | fallback track title `Castorice - Epitaph` (header tooltip, music panel) |
| `src/lib/demoPresence.ts` | 40 | `meroo-landing - src` (dev demo only) |
| `src/components/AnimePanel.tsx` | 133 | `title` tooltip `... - 4/12 episodes` |
| `src/components/Hud.tsx` | 71 | `... is not playable here - click to retry` |
| `src/components/MusicPlayer.tsx` | 214 | `Audio only - the video stays hidden. ...` |
| `src/components/Tutorial.tsx` | 24 | `I keep it lit for you - what you are playing ...` |
| `src/components/Tutorial.tsx` | 42 | `I remember them all - and I remember you most.` |
| `src/components/ViewsPill.tsx` | 6 | placeholder glyph `-` |

**Why:** the character is banned outright in text the agent writes; five of these are read by visitors.
**Fix:** comma, colon, parentheses, or split the sentence. The `ViewsPill` placeholder can become `0`
or `--` (two hyphens), which is not an em dash.

### 2. Text below WCAG AA contrast - R-25

Measured ratios against the composited panel background (need 4.5:1):

| Text | Class | Size | Ratio |
|---|---|---|---|
| `views` | `text-zinc-600` | 9px | **2.53** |
| `Indonesia` | `text-zinc-600` | 8.5px | **2.65** |
| `Soft Tissue` (album) | `text-zinc-500` | 8.5px | 4.09 |
| `Playing` | `text-zinc-500` | 10px | 4.09 |
| `JavaScript` (tag) | `text-zinc-500` | 8.5px | 4.11 |
| `@sengokunadeko__` | `text-zinc-500` | 10px | 4.24 |
| `01:12` | `text-zinc-500` | 8.5px | 4.24 |
| `discord presence · realtime` | `text-zinc-500` | 9px | 4.24 |

**Why:** two labels are barely visible, and six more sit just under the threshold at 8.5-10px,
the size where low contrast hurts most.
**Fix:** `zinc-600` → `zinc-400` for the two worst, `zinc-500` → `zinc-400` for the small mono labels.
`zinc-400` measures 7.4-7.5:1 in the same spots.

### 3. Tap targets under 44x44 at 360 and 390 - R-03

Nine controls, measured at both widths:

- tutorial `SKIP` 25x13
- tutorial `NEXT` 64x27
- three header social icons 32x32
- `CASTORICE` button 99x32
- `Play here` and `Open source` 33px tall

**Why:** on a phone these are the only ways to skip the tutorial, open the archive, or act on the
activity card, and all of them are smaller than a fingertip.
**Fix:** keep the visual size, add padding or a `::after` hit area to reach 44x44
(`p-3` on the 32px icon buttons, `py-2.5` on the tutorial pair, `min-h-11` on the two activity actions).

### 4. Focus escapes an open dialog - R-32

Verified trail inside the contact dialog (`aria-modal="true"`):
`INPUT` → `TEXTAREA` → `Send message` → `DM` → **HUD header controls `[OUTSIDE]`** → ...
14 tabs later focus returns to the dialog input.

**Why:** keyboard users tab into content that is visually covered by the modal, so the next
`Enter` press can trigger something they cannot see. `CastoriceViewer` has the same shape
(no focus trap, no `inert` on the background) by code inspection.
**Fix:** trap `Tab`/`Shift+Tab` inside the dialog, move focus to the dialog on open, return it to
the opener on close, and mark the HUD shell `inert` while a dialog is open.

### 5. Contact form steals focus every ~30 seconds - R-32

`Hud.tsx:434` passes an inline arrow (`onClose={() => setContactOpen(false)}`), so the effect in
`ContactModal.tsx:44` re-runs on every HUD re-render and calls `nameRef.current?.focus()` again.
Measured: message textarea focused, then after 35s the active element was the name input
(`placeholder="who is this?"`). The HUD re-renders on the 30s clock, the 20s presence poll and
every BGM state change.

**Why:** a visitor typing a message loses the caret mid-sentence.
**Fix:** split the effect: focus once on mount (`[]`), and keep the Escape listener separate with a
`useCallback`-stable `onClose` or a ref.

### 6. Missing `footer` landmark, flat heading outline - R-39

Landmarks present: `main` 1, `header` 1, `nav` 1, **`footer` 0**.
Heading outline: a single `H1: meroo__`, no `h2` for the four panels.

**Why:** the gate requires the four landmarks and no skipped levels; screen reader users get one
heading for a page that has four distinct regions.
**Fix:** wrap the bottom status line (or the tab bar) in `<footer>`, and give each panel head an `h2`
visually styled as the current label.

### 7. Images ship without dimensions - R-40

12 `<img>` elements: 0 with `width`/`height` attributes, computed `aspect-ratio: auto` on all,
8 with `loading="lazy"` (album art, app icons, six MAL covers).

**Why:** the gate item fails even though today every image sits in a fixed-size container, so the
real CLS risk is low. Adding attributes also removes the layout work at first paint.
**Fix:** add `width`/`height` (or `aspect-ratio` in the wrapper) per image; keep lazy loading.

### 8. Long-running motion with no pause control - R-39

Declared infinite animations above 5s: `aurora-drift` 24s, `marquee` 38s, `spin-slow` 18s,
`gradient-pan` 9s, `ring-spin` 7s, `float-soft` 7s (plus `status-pulse` 2.4s, `eq` 0.9s).
`prefers-reduced-motion` stops all of them, which is the other half of the rule.

**Why:** anything moving longer than 5 seconds needs a pause affordance, and the ambient layer
never settles.
**Fix:** cheapest honest option is a motion toggle in the header next to the BGM button that adds
a `no-ambient-motion` class; alternatively let the aurora finish one pass and stop.

## MEDIUM - Purpose-Gate (owner direction, needs a keep/drop decision)

Per R-37 these are identity choices, not defects. Each needs one line from the owner: keep it
(written reason recorded) or drop it.

### 9. Glassmorphism on 7+ surfaces - R-10

`blur(14px)` on `.hud-panel` (`index.css:396`, four panels), plus `backdrop-blur-md` on the contact,
archive and music overlays, and `backdrop-blur` on the archive close button. The dose cap is 1-2.

### 10. Aurora blobs + violet/fuchsia/cyan gradients as the base treatment - R-01

Three `.aurora-blob` layers (`index.css:103`), gradient buttons (`from-violet-600 via-indigo-600
to-cyan-600`), gradient text, and a violet-black page base. This is the closest cluster to the
"generic blue-purple gradient" pattern in the project.

### 11. `grid-lines` background over the whole HUD and intro - R-07

`index.css:112`, applied full-bleed in `Background.tsx`. A grid needs a stated identity reason or
it reads as the default "tech" texture.

### 12. Six active hues - R-29

violet, fuchsia, sky/cyan, amber, emerald and red all appear as UI states. The cap is 2-3 core
colours plus 1 accent.

### 13. Glow on panels, buttons, avatar ring, borders and background at once - R-13

`shadow-[0_0_22px_-4px_rgba(168,85,247,0.8)]` on the avatar, violet shadows on the primary buttons,
radial gradients inside every panel, plus the aurora layer.

### 14. Inter and JetBrains Mono with no written reason - R-06

`index.css:9-11`: Chakra Petch is defensible (it carries the character's voice), but Inter and
JetBrains Mono are the two AI-default picks and nothing in the repo says why.

### 15. One icon library across 13 components - R-04

`lucide-react` is imported in 13 files; the brand glyphs in `icons.tsx` are custom. R-04 asks for
icons chosen by relevance, not by library look.

### 16. `cursor: none` on 32 of 32 controls - R-39

The custom cursor is owner direction ("mouse effects"), but R-39 requires `cursor: pointer` on
every enabled control. Today every button and link reports `cursor: none` for fine pointers.

### 17. Capsule status pills - R-09

Header pills combine `rounded-full` + 1px border + uppercase + 9px wide tracking + a dot, which is
the full capsule-badge combination the rule warns about. They do carry real status, so the fix may
just be dropping one or two of the four signals.

### 18. No `DESIGN.md`, dials not written down - R-31 / R-37

No `DESIGN.md` or `AGENTS.md` exists. Palette, type and motion reasons live only in this audit and
in chat. The three dials (ENERGY / RHYTHM / MOTION) are not declared anywhere.

## LOW - Quality Locks and hygiene

### 19. Em dash in `README.md` - R-02

Lines 11-19 use `-` as a list separator. Documentation, not UI, but still agent-written text.

### 20. Dead files and dead CSS

- `src/components/Footer.tsx` (3.9 KB) and `src/components/Navbar.tsx` (7.4 KB): imported nowhere.
- `.glass` / `.glass-strong` (`index.css:66`, `:77`): no component uses them.
- `backup/favicon-trace.svg`: 2.1 MB, unreferenced.

### 21. Render-blocking third-party stylesheet - R-40

`index.html:41-44` loads Google Fonts CSS in `<head>`. `display=swap` mitigates the flash, but the
request still blocks first render; self-hosting the three families removes it.

### 22. Hover and active states are colour-only on icon buttons - R-39

Header icon buttons change border and text colour on hover and `active:scale-95`, but the disabled
and pressed states have no non-colour cue. Small, but the rule asks for a state that survives
colour blindness.

### 23. Dead anchor when the Discord ID is missing - R-26

`ContactModal.tsx:221,284,313` render `href={discordProfileUrl ?? '#'}`. With `VITE_DISCORD_USER_ID`
unset (the `.env.example` default) three links point at `#`.
