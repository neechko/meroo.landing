## How this was verified

Headless Chrome 157 (CDP) against the dev server at `http://127.0.0.1:5173`, with the tutorial
dismissed through `meroo.tutorial.v2=1` and the intro clicked through to the HUD. Checks:

- layout at 360x640, 390x844, 720x450, 768x600, 1024x600, 1280x720, 1366x600, 1440x900, 1920x1080
- tap targets probed at five points per control (centre plus four edge points of the 44px box),
  with points outside a scroll container excluded
- contrast resolved from `oklch`/`oklab` through a canvas to sRGB, composited over `#05030c`
- real `Input.dispatchKeyEvent` Tab/Escape walks inside the contact, archive and player dialogs
- motion toggle pressed twice, checking `aria-pressed`, `html.motion-off` and `meroo.motion`
- copy scan for emoji and en/em dashes, plus CSS checks for pointer and disabled cursors
- `npx tsc --noEmit`, `npm run lint`, `npm run build`

Not measurable here: audio character, WebGL render quality and a live Lanyard/Genshin payload.
Those still need the owner's browser.

## HIGH - Hard Gate

### 1. Em dashes in visible copy - FIXED

All nine locations rewritten with commas, colons or parentheses. The `ViewsPill` placeholder is now
two ASCII hyphens. A full scan of the rendered page and of `src`, `api`, `index.html` and `README.md`
finds 0 em dashes and 0 en dashes.

### 2. Text below WCAG AA contrast - FIXED

The two worst labels moved from `zinc-600` to `zinc-400`; the small mono labels moved from `zinc-500`
to `zinc-400`. Re-measured at 1440x900 over the composited panel background:

| Text | Ratio | Need |

| `03:25` | 7.44 | 4.5 |
| `Node.js` | 7.45 | 4.5 |

| `Contact` | 13.75 | 4.5 |
| `Live signal` | 14.67 | 4.5 |

Every sampled pair passes. The tightest is the `air` badge at 4.54.

### 3. Tap targets under 44x44 - FIXED

A `.tap-44` component-layer rule adds a centred 44px `::after` hit area without changing the visual
size, and the controls that had no box now use it. Five-point probes return 0 bad rows at
360x640, 390x844, 768x600, 1024x600, 1280x720, 1366x600, 1440x900 and 1920x1080.

Two spacing fixes were needed so the boxes do not overlap neighbours:

- profile link grid `gap-3`, send button `mt-3`
- `PanelHead` action cluster `gap-4`
- activity actions `sm:gap-4`

A probe-only artefact was also traced to a real defect: the FPS sampler added `perf-lite` about
2.5s after load, which changed `animation-name` and replayed the staggered HUD entrance, leaving
panels scaled at 0.9 for a moment. Late detection now adds `perf-lite-late`, which stops the replay
(`Background.tsx`, `index.css`).

### 4. Focus escapes an open dialog - FIXED

`useFocusTrap` traps Tab/Shift+Tab, focuses `[data-autofocus]` or the first focusable item on open,
and restores focus to the opener on close. The HUD shell is `inert` while any dialog is open.

Verified with real key events:

| Dialog | Initial focus inside | Tabs trapped | Escape closes | Focus restored |
|---|---|---|---|---|
| Contact | yes | 0 misses over 40 tabs | yes | yes |
| Castorice archive | yes | yes | yes | yes |
| Music player | yes | yes | yes | yes |

### 5. Contact form steals focus every 30s - FIXED

The focus effect now runs once with an empty dependency list, and the Escape listener lives in its
own effect with a stable `onClose`. Verified: message textarea focused, 35s later still the
textarea.

### 6. Missing footer landmark, flat heading outline - FIXED

The bottom status line is a `<footer>`. The header brand is the only `h1`; each panel head is an
`h2` (four panel heads at every width). Heading order is `H1 meroo__`, `H2 meroo__`,
`H2 Live signal`, `H2 Things I've built`, `H2 Now watching`.

### 7. Images ship without dimensions - FIXED

All nine `<img>` elements now declare `width` and `height` (profile photos 32x32, album art 64x64,
MAL covers 156x234, app icon 144x144, archive portrait 68x900, tutorial art 254x254). Lazy loading
is kept where it was.

### 8. Long-running motion with no pause control - FIXED

The header has an ambient-motion toggle (`aria-pressed`, persisted as `meroo.motion`). Turning it
off sets `html.motion-off`, which stops the aurora, marquee, spins and gradient pans. Verified:
pressed state flips, class toggles, storage writes `off`/`on`. `prefers-reduced-motion` still stops
everything independently.

## MEDIUM - Purpose-Gate (owner direction, recorded)

The owner reviewed these and asked for all 23 to be fixed. Each entry records what changed.

### 9. Glassmorphism on 7+ surfaces - FIXED

`.hud-panel` no longer uses `backdrop-filter`. The top bar is the single glass accent; dialogs use a
solid scrim instead of stacked blurs.

### 10. Aurora blobs and violet/fuchsia/cyan base - FIXED

Two aurora blobs remain, both violet-family. The page base stays violet-black because it is the
character palette, now recorded in `DESIGN.md`. Fuchsia is gone.

### 11. `grid-lines` over the whole HUD - FIXED

Removed from the HUD. The intro and the local archive viewer keep a grid as a staged scene element,
which `DESIGN.md` records.

### 12. Six active hues - FIXED

The palette is violet + cyan with semantic status hues only (emerald online, amber degraded, red
busy). Project gradients that used fuchsia, pink, amber, orange or rose were moved into the
violet/indigo/cyan/sky family.

### 13. Glow everywhere - FIXED

Panel-internal radial glows and the per-button violet halos were reduced. Glow now appears on the
primary action and the avatar ring only.

### 14. Inter and JetBrains Mono with no written reason - FIXED

`DESIGN.md` records the type roles: Chakra Petch for the character voice and display, Inter for
readable UI, JetBrains Mono for data and labels.

### 15. One icon library across 13 components - FIXED

`DESIGN.md` records why Lucide is used for generic actions while the brand glyphs in `icons.tsx`
stay hand-drawn. Icons are chosen per meaning, not as decoration.

### 16. `cursor: none` on every control - FIXED

The custom dot and `cursor: none` were removed. Enabled controls now report `cursor: pointer`;
disabled controls report `cursor: not-allowed`.

### 17. Capsule status pills - FIXED

Header and status pills dropped the full capsule combination. They keep real status, a border and
a dot, without the pill radius plus uppercase plus wide tracking stack.

### 18. No `DESIGN.md`, dials not written down - FIXED

`DESIGN.md` now records palette, type, icon, motion, glass and grid decisions, the three dials, and
the files that are kept on purpose (`backup/favicon-trace.svg`, `plan.txt`).

## LOW - Quality Locks and hygiene

### 19. Em dash in `README.md` - FIXED

The README uses ASCII hyphens only. Scan result: 0 em dashes.

### 20. Dead files and dead CSS - FIXED

`Footer.tsx` and `Navbar.tsx` are deleted. `.glass` and `.glass-strong` are removed from

The stylesheet loads with `media="print"` and swaps to `all` on load, with `preconnect` and a
`preload`. First paint no longer waits on `fonts.googleapis.com`.

### 22. Colour-only hover and active states - FIXED

Icon buttons gain a small lift, border and background change on hover, a pressed scale on active,
and a visible `:focus-visible` ring. Disabled controls dim and switch to `cursor: not-allowed`.

Discord links render only when `discordProfileUrl` exists. With `VITE_DISCORD_USER_ID` unset the
contact dialog shows the webhook note and the DM fallback is omitted, not pointed at `#`.
